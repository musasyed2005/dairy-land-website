# Dairy Land website

Static restaurant website for Dairy Land, 310 Cavalcade Street, Houston, TX.

## Preview

Open `index.html` in a browser. Keep `assets/` next to it.

## Updates

- Edit visible menu prices, text and hours in `index.html`.
- Store pictures in `assets/` and use relative paths.
- Ordering buttons link to https://dairylandhtx.cloveronline.com/menu/all.
- The displayed menu does not automatically synchronize with the ordering system. Update both when prices or availability change.

## Hosting

Publish the repository root as a static website. No build command or dependencies are required.

## Before publishing

Confirm menu availability and prices, verify hours, and test an order through the ordering page.
